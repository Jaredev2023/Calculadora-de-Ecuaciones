Sistema de Ecuaciones 2x2

Un sistema de ecuaciones 2x2 permite encontrar el valor de dos incógnitas utilizando dos ecuaciones lineales.

Forma general:

a₁x + b₁y = c₁
a₂x + b₂y = c₂

El punto donde las rectas se intersectan representa la solución del sistema.
