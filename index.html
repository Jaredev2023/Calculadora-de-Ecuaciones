Calculadora de Ecuaciones

Aplicación diseñada para resolver ecuaciones de primer grado, segundo grado y sistemas de ecuaciones 2x2.

Ecuación de Primer Grado

y = mx + b

Una ecuación de primer grado representa una línea recta. La variable m indica la pendiente y b el punto donde la recta cruza el eje y.

Ecuación de Segundo Grado

ax² + bx + c = 0

Una ecuación de segundo grado forma una parábola. Se utiliza para encontrar puntos máximos, mínimos y las raíces de la ecuación.

Sistema 2x2

a1x + b1y = c1

Un sistema 2x2 permite encontrar el valor de dos incógnitas utilizando dos ecuaciones lineales al mismo tiempo.

a2x + b2y = c2
